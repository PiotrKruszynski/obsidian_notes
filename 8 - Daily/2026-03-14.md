# 🚀 Big Data & AI Engineering: Architecture & Case Studies

## 1. Architektury Systemów Agentowych i RAG

Współczesne systemy Big Data ewoluują w stronę **Multi-Agent Pipelines**, gdzie LLM pełni rolę "procesora" sterującego narzędziami.

- **RAG (Retrieval-Augmented Generation) w skali Enterprise:**
    - **Proces:** Embedding (tekst -> wektor) -> Baza wektorowa (np. ChromaDB) -> Pobranie top-K fragmentów -> Prompt z wstrzykniętym kontekstem.
    - **Wyzywania inżynieryjne:** Zarządzanie liczbą tokenów, poprawne parsowanie tabel w dokumentach, nakładanie się sekcji (chunking strategies).
    - **Indeksowanie poddomen:** Tworzenie oddzielnych indeksów dla różnych kategorii danych (np. katalogi vs cenniki) w celu poprawy precyzji wyszukiwania.
- **Orkiestracja Agentów:**
    - **LangGraph:** Zarządzanie przepływem pracy agentów za pomocą grafów stanów.
    - **Pętla ReAct (Reason + Act):** Cykl, w którym agent planuje działanie, wykonuje je (np. wywołanie API SQL) i analizuje wynik przed kolejnym krokiem.
    - **Infrastruktura:** Wykorzystanie **Groq** do ultra-szybkiej inferencji LLM (kluczowe przy systemach real-time).

## 2. Scalable Media Processing (Case Study: Azure/Video)

Projektowanie potoków przetwarzania wideo wymaga ścisłej integracji usług chmurowych z narzędziami analitycznymi.

- **Stos technologiczny:** Azure Video Indexer + Azure Functions + Databricks.
- **Pipeline produkcyjny:**
    - Integracja przez **Service Principal** dla bezpieczeństwa komunikacji między usługami.
    - **CI/CD:** Automatyzacja wdrożeń na środowiska Dev/Test/Prod przy użyciu pipeline'ów DevOps.
    - **Monitoring:** Log Analytics do śledzenia statusu transkrypcji i błędów w modelach Whisper.
- **Analityka sygnału:** Wykorzystanie modeli Whisper do transkrypcji i analizy timestampów w celu synchronizacji napisów (WCAG 2.1).

## 3. Computer Vision i Vision APIs

Zamiast trenować modele od zera, inżynier Big Data integruje gotowe **Vision APIs** (Azure/AWS) do ekstrakcji metadanych z nieustrukturyzowanych zbiorów.

- **Kluczowe operacje:**
    - **OCR & Form Recognizer:** Ekstrakcja danych strukturalnych z dokumentów (faktury, liczniki energii).
    - **Analiza przestrzenna:** Mapowanie ruchu obiektów w czasie rzeczywistym.
    - **Custom Vision:** Fine-tuning klasyfikacji obrazów dla specyficznych nisz (np. kontrola jakości w produkcji).

## 4. Teoria Percepcji w Wizualizacji Danych (Data Ops)

Zrozumienie psychologii poznawczej jest niezbędne do projektowania dashboardów, które realnie wspierają decyzje biznesowe.

- **Ograniczenia sprzętowe człowieka:** Pamięć robocza to tylko **4 ± 1 elementy**. Przekroczenie tego limitu (np. zbyt wiele kolorów na wykresie) powoduje paraliż analityczny.
- **System 1 vs System 2:** Projektuj wizualizacje pod System 1 (szybka, przedświadoma percepcja długości i pozycji), aby odciążyć System 2 (powolne wnioskowanie logiczne).
- **Hierarchia dokładności percepcyjnej:** Najdokładniejsza jest **pozycja na wspólnej osi**. Kolejno: długość, kąt, powierzchnia, objętość (najmniej dokładna).

## 5. Modelowanie Ryzyka i Etyka

- **Finanse:** Wykorzystanie modeli zmienności do szacowania **VaR (Value at Risk)** – kluczowe w systemach Big Data analizujących portfele inwestycyjne.
- **Zagrożenia AI:** Halucynacje modeli, brak empatii w automatycznych decyzjach (mechanicyzm) oraz ryzyko inwigilacji (np. chiński system kredytu społecznego oparty na danych behawioralnych).
- **Privacy by Design:** Ochrona danych osobowych w systemach AI jako wymóg architektury, a nie dodatek.
