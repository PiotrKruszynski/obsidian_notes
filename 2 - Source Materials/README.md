# 2 - Source Materials — warstwa źródeł (raw)

Trwałe, niemutowalne źródła wiedzy: PDF-y, wklejone artykuły, transkrypty wykładów, surowe dumpy z dokumentacji, dłuższe wyciągi z rozmów z LLM.

**Zasady:**

- Pliki tutaj są **tylko do czytania**. Agent ich nie edytuje, nie kasuje, nie przenosi — traktuje wyłącznie jako materiał wejściowy.
- Z plików stąd robi się `ingest` → atomowe notatki w `5 - Notes/`.
- Notatka powstała z pliku stąd dostaje w frontmatter `źródło: 2 - Source Materials/nazwa-pliku` — żeby dało się wrócić i zweryfikować twierdzenia.
- Plik zostaje tu na zawsze, nawet po ingestcie. To archiwum dowodowe, nie poczekalnia.

**Różnica względem `1 - Raw Notes`:** tu trafiają trwałe źródła (dokumenty, artykuły), tam — ulotne, luźne wnioski z sesji nauki, które po rozłożeniu można wyczyścić.
