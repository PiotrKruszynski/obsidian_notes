>[! Definition ]
>Data Lake to **centralny storage (najczęściej object storage)**, gdzie trzymasz **surowe dane w dowolnym formacie**, a schemat nakładasz dopiero przy odczycie — dziś standard to S3 + Spark, nie Hadoop.
