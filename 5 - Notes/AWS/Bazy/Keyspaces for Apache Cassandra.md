>[! ]
>-  managed Apache Cassandra-compatible database service
>- _Apache Cassandra_ is an open-source NoSQL distributed database
>- _serverless_, _scalable_, [[high availability]], fully managed by AWS
>- automatically scale tables up/dowwn based on the application's traffic
>- tables are replicated 3 times across multiple AZ
>- using the _Cassandra Query Language_ **CQL**
>- single-digit milisecond latency at any scale, 1000x of requests per second
>- **capacity:** 
>	- on-demand mode 
>	- provisioned mode with auto-scaling
>- **encryption**
>- **backup**
>- **PITR** up to 35 days

**Use cases**: store IoT devices info, time-series data
