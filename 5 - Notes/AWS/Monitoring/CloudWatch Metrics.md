>[! ]
>metrics for every services in AWS

**Metric** - variable to monitor (CPUUtilization.., bucket size)
- belong to namespaces
- have _dimension_, up to 30 per metric
- have timestamps
- can create CloudWatch dashboards of metric
- can create CloudWarch Custom Metrics (for RAM exaple)
